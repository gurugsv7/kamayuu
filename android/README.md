# Kamayuu bundled Android app

This is now a Capacitor 8.6 project, not the earlier Trusted Web Activity.
Package `in.builtbygsv.kamayuu`; version code 2, version name 0.2.0;
minimum Android 7 / API 24; compile and target API 36.

The package embeds `dist-mobile` and runs locally through Capacitor's WebView.
Online play still requires the Supabase backend and approved account setup.
The earlier TWA prototype is preserved in Git history at commit `6132a22` and
in the original laptop's ignored `work/android-twa-prototype` folder.

Build, cloud setup, signing and remaining release checks are documented in
[`../docs/mobile-cloud-setup.md`](../docs/mobile-cloud-setup.md).
